# Метрическая проверка SceneFlow

План измерения, фиксируемый до получения новых прогнозов.

## Источник и окно

Использовать метрические RGB-D и состояния LIBERO. До первого нового SceneFlow-прогноза источник уточнён: начальное состояние0 завершённой серии task8 (ящик+миска), фиксированные якоря после50 и100управляющих действий. Ранее намеченный старый baseline task72 заменён уже доступной на runtime записью, чтобы ограничить перенос больших файлов и использовать результаты начатого эксперимента. Окна не выбираются по ошибке модели. История берётся до якоря включительно, будущие изображения и положения объектов в инференс не передаются.

Из сохранённого якоря модель один раз генерирует EEF-команды и прогноз сцены. Эти EEF-команды исполняются в восстановленном симуляторе без перепланирования на всём горизонте SceneFlow. Эталон получается из фактически достигнутых поз объектов. Такая проверка оценивает совместный прогноз и исполнение с ошибкой слежения контроллера; фактическое движение захвата сравнивается с предсказанным отдельно. Продолжение старого closed-loop эпизода не считается эталоном для новых команд.

## Соответствия

В начальном RGB-D выбрать точки видимых не-роботических жёстких поверхностей, определить принадлежность геометрии телу по сегментации симулятора и сохранить локальные координаты в системе тела. В будущем переносить те же локальные точки позой этого тела; для неподвижной геометрии точки остаются на месте. Исключить невалидную глубину, фон без идентификатора и геометрию робота. Выборка детерминирована seed=42; равные квоты по видимым телам делают объект различимым на фоне. Записать точные квоты и состав; метрики относятся к этой выборке.

Калибровка, начальные точки, прогноз и эталон приводятся к одной неподвижной системе базы робота в метрах. Проверить начальное совпадение и обратную проекцию до вычисления ошибки.

## Метрики

- Будущий горизонт — 20 шагов при 20 Гц, начальный кадр исключается из ADE/FDE.
- ADE — среднее евклидово расстояние по всем допустимым парам точка–время; FDE — среднее расстояние в последнем кадре. Публиковать количество валидных пар и конечных точек.
- Движущаяся точка: максимальное смещение от начального положения на фиксированном горизонте превышает 1 см по эталону. Группы all/moving/static определяются независимо от прогноза.
- Публиковать две версии: по всем геометрическим соответствиям и по видимым в доступных камерах точкам. Видимость рассчитывать по будущим истинным позам камер, положительной camera z, попаданию в кадр и согласованию с будущей depth при допуске 1 см. Маска не зависит от предсказанной позиции.
- Для каждой группы показать UNITAS и прогноз «точки остаются на месте». Пустые группы обозначать отсутствующим значением, не нулевой ошибкой.
- Не агрегировать зависимые окна как независимые эпизоды; приводить результаты каждого окна и описательное среднее.
- Для каждого жёсткого тела отдельно измерить RMS-остаток совмещения предсказанного облака с начальным лучшим жёстким преобразованием (Kabsch с запретом отражения). Перенос и вращение не дают такой ошибки, деформация даёт. Контроль — тот же остаток по эталону.

Расчёт реализован в `src/stage5_metrics/score.py`. Синтетические проверки покрывают известное движение, финальную окклюзию, неподвижный фон, пустую moving-группу и ошибку начальной системы координат.
